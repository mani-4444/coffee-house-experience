# Drink photos

Drop one photo per drink here, named after the item's `id` in `src/data/menu.ts`:

    kaapi-by-two.jpg   bellam-cortado.jpg   monsooned-malabar-cold-brew.jpg   irani-chai.jpg   …

- `.jpg`, `.png` or `.webp`, at least 1600 px on the long edge, **4:5 portrait** (cropped to 4:5 if not).
- Shoot to `docs/art-direction.md`: daylight from one side, the same marble table, the same angle for every drink.
- Astro generates AVIF/WebP at several sizes at build time, so upload the full-quality original.
- Only drinks with a photo appear in the "In the cups" section, in board order. The section hides when the folder is empty.
